# pi-context-vault v0.3.1

Release date: 2026-09-01

## Highlights

`v0.3.1` is the first npm release of the standalone, Observation-only Context Vault. It keeps large and historical
textual Tool Results recoverable outside active model context, replaces eligible results with bounded receipts, and
exposes exactly three Tools:

- `context_vault_obs_get`
- `context_vault_obs_search`
- `context_vault_status`

Repository indexing and repository context injection are not part of this package; they remain owned by the independent
`pi-repo-context` project.

## Reliability and safety since the v0.3.0 payload

- Observation search now preserves literal and ranked retrieval semantics across common identifier separators, ignores
  empty normalized queries safely, and reports Tool failures through Pi's error channel.
- Search results collapse duplicate artifacts, enforce a byte-accurate total model-output budget, and provide bounded
  search-to-get handoffs that can target deep UTF-8 evidence.
- A disposable bounded Bloom snapshot accelerates search without becoming authoritative state.
- Model-visible status uses an explicit privacy allowlist.
- Manual GC reports quota status explicitly and continues to protect live leases and current-session receipt
  references before retention/quota selection.
- Redaction scanners use monotonic bounded paths for assignments, private keys, and URL credentials, avoiding the
  prior adversarial quadratic behavior.
- The package contains no Repo runtime, dependencies, configuration ownership, or mutable state.

The README now leads with the core archival/search workflow and reports the preregistered pressure-task evidence with
its sample-size and causality limitations.

## Compatibility and dependency contract

- Node.js `>=22.19.0`.
- Pi core modules are supplied by the host, as required by the Pi package contract:

```json
{
  "@earendil-works/pi-coding-agent": "*",
  "typebox": "*"
}
```

- Reproducible development and CI remain pinned to Pi `0.84.1` and TypeBox `1.3.7`.
- Package-install smoke validation also passed against Pi `0.84.4` and TypeBox `1.3.23` during release preparation.
- There are no package runtime dependencies.

## Install

From npm:

```bash
pi install npm:pi-context-vault@0.3.1
```

Or from the matching immutable Git tag:

```bash
pi install git:github.com/Fubuyunhua/pi-context-vault@v0.3.1
```

Restart Pi after installation, then run:

```text
/context-vault doctor
/context-vault status
```

## Upgrade and evidence retention

Stop active Pi sessions before replacing an older installation, install `v0.3.1`, and restart Pi into a new session.
Existing Vault artifacts and Observation metadata are preserved. Uninstalling or upgrading does not delete evidence;
manual `/context-vault gc` remains the only supported retention/quota action.

Context Vault never reads, migrates, collects, or deletes legacy Repo Map state or `pi-repo-context` state.
