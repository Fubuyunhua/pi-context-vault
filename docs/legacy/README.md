# Historical material

Files under `docs/legacy/` describe the pre-split combined Context Vault / Repo Map product, its local ablation
harness, or the frozen mixed-product release candidate. They remain in Git for provenance, are superseded by
Specification 0018, and are excluded from the npm package. They are not evidence of current Vault behavior, a Provider
benchmark, or a published split release.

- `releases/v0.2.0-rc.md` is the frozen, untagged pre-split mixed-product release-candidate note formerly kept in the
  active release directory. It does not describe a Context Vault-only or Repo Context release.
